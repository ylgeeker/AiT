# Code of Conduct

## Scope

This Code of Conduct applies to all participants in the AiT project, including contributors and maintainers, in project spaces such as issues, pull requests, code review, and related discussions.

## Expected behavior

Participants are expected to:

- Treat others with respect and professionalism
- Engage in constructive technical discussion
- Accept good-faith feedback and collaborate toward project goals
- Foster an inclusive environment for contributors of diverse backgrounds

## Unacceptable behavior

The following conduct is prohibited:

- Harassment, discrimination, or derogatory comments related to personal attributes
- Threats, intimidation, or personal attacks
- Deliberate disclosure of others' private information without consent
- Conduct that disrupts collaboration or undermines project governance
- Other behavior that a reasonable person would consider inappropriate in a professional open-source community

## Maintainer responsibilities

Project maintainers are responsible for:

- Clarifying and applying this Code of Conduct
- Taking appropriate corrective action in response to violations
- Protecting reporters from retaliation when handling reports in good faith

Reports may be submitted to the project maintainers at **conduct@os-artificer.org** (placeholder; replace with the project's published contact when available).
