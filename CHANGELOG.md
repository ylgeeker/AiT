# Changelog

Product and CLI functional changes only. Documentation-only updates are not recorded here.

## How to record a change

- Add new items to [docs/changelog/unreleased.md](docs/changelog/unreleased.md).
- Group items by tool (`ait`, `aissh`, `aihost`, `aiimg`, `ailog`).
- Write each item as one plain sentence saying what the user can do. Prefix it with `【Added】`, `【Changed】`, or `【Fixed】`.
- When a version is released, move those items into `docs/changelog/vX.Y.Z.md` (the file name is the version, including the `v`) and add a link below.
