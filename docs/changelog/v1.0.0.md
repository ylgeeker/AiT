# v1.0.0

This is the first release of AiT, a command-line toolbox for everyday operations work. It ships five tools: `ait`, `aissh`, `aihost`, `aiimg`, and `ailog`. `ait` also includes a built-in AI assistant.

### ait

- 【Added】Running `ait` on its own starts an AI assistant that can carry out operations tasks for you. You describe what you want in plain language, and it runs commands step by step.
- 【Added】The assistant runs read-only commands such as `ls` right away. It asks before running anything that changes files, and it always asks again before risky commands such as `rm -rf`.
- 【Added】You can point the assistant at a remote server with `ait agent connect user@host`, and it will work on that machine over SSH.
- 【Added】You can list models with `ait agent model list`, turn cloud providers on or off, and set up a local Ollama model. AI features are still experimental. They are on by default, and you can turn them off in the configuration.
- 【Added】You can run any AiT tool through `ait`, for example `ait ssh user@host` or `ait log search error`.
- 【Added】`ait shell` opens a toolbox prompt where `install`, `update`, and `upgrade` download the official tools from GitHub Releases. The easiest way to get started is `go install github.com/os-artificer/AiT/cmd/ait@latest`, then run `install` inside `ait shell`.

### aissh

- 【Added】`aissh` connects to servers the same way `ssh` does, and it reads your `~/.ssh/config`. It also works through jump hosts (`-J`).
- 【Added】The remote prompt shows the current directory and Git branch, so you always know where you are.
- 【Added】You can save a connection with `--save` or give it a name with `--alias`. Later, `aissh session --list` shows your saved sessions and `aissh session --load` reconnects and restores the previous screen and working directory.
- 【Added】With `--tmux`, remote programs keep running after you disconnect.
- 【Added】`aissh get` and `aissh put` copy files to and from a server. Inside a session, `!ait get` and `!ait put` do the same without opening a new connection, and they also work through multiple SSH hops. A progress line shows how far the copy has gone, and Ctrl+C cancels it.
- 【Added】Inside a session, `!ait local` switches to your own machine and `!ait remote` switches back. `!ait suspend` saves the session so you can resume it later.
- 【Added】`aissh shell` opens a local prompt for managing sessions. It also runs your own scripts and ordinary system commands.
- 【Added】`aissh config` lets you create, view, edit, and check the configuration file.

### aihost

- 【Added】`aihost top` shows a live dashboard of your machine, with CPU, memory, disk, network, and protocol charts, and a process list.
- 【Added】In the process list, you can press `/` to search, press Enter to see details and recent log lines for a process, and press `x` to stop it after confirming.
- 【Added】Commands such as `aihost snapshot`, `aihost cpu`, and `aihost proc` print the same information once, as text or JSON. `aihost` runs on Linux, macOS, and Windows.

### aiimg

- 【Added】`aiimg` reads the details stored in a photo, such as the camera, the time it was taken, and where it was taken. It turns GPS coordinates into a readable place name.
- 【Added】`aiimg set` and `aiimg clear` change or remove those details on JPEG files. By default the result is saved as a new copy (`*_aiimg.jpg`), so the original stays untouched.

### ailog

- 【Added】`ailog` lets you view and search system logs with one command on Linux, macOS, and Windows. It uses the system's own log tools when they are available and falls back to reading log files directly.
- 【Added】You can search by keywords, regular expressions, or a combined expression like `error AND NOT timeout`. You can also limit results by time, follow new lines as they arrive, or output JSON.
